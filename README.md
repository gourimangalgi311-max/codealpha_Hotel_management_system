# 🏨 Grand Stay Hotel – Hotel Management System


## 📌 Project Overview
Grand Stay Hotel is a Java-based Hotel Management System developed to provide a simple and user-friendly platform for hotel room reservations and hotel service management.
The project allows customers to explore available rooms, make room reservations, manage bookings, explore hotel facilities, and access other hotel services. It also provides an admin dashboard to manage hotel-related activities.
This project was developed as part of my **Java Programming Internship at Code Alpha**.


## ✨ Features
- **Home Page:** Explore the hotel and its services.
- **Customer Registration:** Create a customer account.
- **Customer Login:** Access the customer portal.
- **Room Booking:** Book rooms according to customer preferences.
- **Room Categories:** Standard Room, Deluxe Room, and Luxury Suite.
- **Booking History:** View previous bookings.
- **Booking Cancellation:** Option for customers to cancel bookings.
- **Event Booking:** Book hotel facilities for special events.
- **Food Services:** Explore food and dining options.
- **Payment Management:** Access booking payment options.
- **Admin Dashboard:** Manage hotel booking-related activities.
- **Customer Profile:** View and manage customer details.

## 🚀 How to Run the Project
### Prerequisites
- Java JDK 21
- Apache Maven
- Visual Studio Code
- Web browser


### Steps
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Navigate to the project directory.
5. Run the following command:
```bash
mvn clean compile
```
6. Start the application:
```bash
mvn exec:java
```
7. Open your browser and visit:
```text
http://localhost:8080
```
8. The Grand Stay Hotel website will open.
